# サイスピ P1実装記録

更新日: 2026-09-15

## 対象

現行計画書 v1.1 のP1を実装した。基準は `chameleonjp-lab/sainome@2103b8a91f214fc8698d119113417d5360f990f0` で、元リポジトリは変更していない。

P1では、元版と同じ盤面・カメラ・サイコロ・キャラクター・斜め操作を使い、中央の埋まったサイコロへ登って上昇完了するところまでを用意した。目標10個、競技時計、結果、保存、ランキングはP2以降の対象である。

## 流用した接続点

- `js/camera-framing.js`: 元版の7×7盤面の投影とカメラ位置 `(7.8, 9.2, 8.8)` を維持した。
- `js/dice.js`: 元版の基本姿勢と6面の回転規則をそのまま使った。
- `js/input-direction.js`: 最小距離24、斜め比率0.3、4方向の対応を維持した。
- `js/performance-profile.js`: タッチ向けと標準の移動時間を一律変更せず継承した。
- `js/webgl-game.js`: 元版の盤面描画、サイコロ造形、キャラクター造形、床移動、登る動き、サイコロの転がりを新作の実行経路へ分離した。

元版の `findTriggeredGroups`、特殊な1の処理、沈下後の補充、300秒終了、旧得点計算は新作のファイルへ入れていない。

## P1で確認したこと

- `npm test`: 18件成功。
- `npm run check:syntax`: `js/`、`scripts/`、`test/`の21ファイルで成功。
- 起動要求の世代無効化、P1状態・操作キュー、アニメーション待機のキャンセル、描画リソース解放を自己検査した。
- 固定10座標や目の生成、計測、保存、ランキングは未実装のためP1の合格範囲に含めていない。
- ローカル配信とブラウザ自動検査は、検査環境のブラウザ実行ファイルが利用できず未実施。
- iPhone 17 Pro Safariでの実機確認は未実施。
