# Supabaseランキング公開準備

## 現在の確認結果

- Supabaseプロジェクト: `chameleonJP-Lab`
- 既存の公開ランキングゲーム: `sainome_300_seconds`（サイノメ）
- `saisupi`: `public.games`に登録行なし
- 既存RPC: `record_game_play`、`submit_score`、`get_best_score_ranking`

サイスピ側は、公開キーで`public.games`の`saisupi`登録を読み取り、登録がない間は「オンラインランキングは準備中です」と表示する。サイノメの行やデータは読み替えない。

## 所有者が公開前に確認すること

1. サイノメと同じ運用ルールで、サイスピ用のゲームID `saisupi` を登録する。
2. スコア単位を0.01秒の整数、順位を短い時間が上位になる小さい順として設定する。
3. `record_game_play` がゲーム開始1回を受け付け、`submit_score` が完走スコアを自己ベスト・ランキングへ登録することを、使い捨てのテスト名で確認する。
4. `games`、ランキング参照、RPCの公開権限とRLSがサイノメの公開構成と同等であることを確認する。
5. 登録済み環境でサイスピの結果画面を開き、自己ベスト・上位10件・再送・重複送信を確認する。

このPRでは本番データベースへのINSERT/UPDATE、権限変更、RLS変更を実行していない。登録方法はプロジェクトの既存マイグレーション・管理手順に合わせ、所有者がレビューして適用する。
