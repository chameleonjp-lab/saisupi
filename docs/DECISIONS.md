## 1. 固定仕様の正本

U01〜U10は[実装計画書](IMPLEMENTATION_PLAN.md)第2節に集約する。内容は変更していない。完成条件は同書第11・12節、検査条件は[受入検査](ACCEPTANCE_TESTS.md)を参照する。

U11（実装計画と資料をこのリポジトリへ保存する依頼）は、初回P0としてPR #1で反映された。未採用案の一括承認やゲーム実装の完了を意味しない。

## 2. 未指定の細部を補う実装案

以下はユーザーが確定した値ではない。採用を決める際は根拠となる指示と対象版を記録する。今回の指示整理ではD01〜D08を承認済みへ変更しない。公開競技の条件を、未確定のまま実装者の判断で固定しない。

| ID | 実装案 | 決める時点・扱い |
|---|---|---|
| D01 | サイコロは1個、目標の達成順は自由。 | P1〜P2の設計確認。ユーザーの完走形式を最小構成で具体化する案。 |
| D02 | 配置案Aの10座標、サイコロ中央、キャラクター隣接マス。 | P2前に画像と座標で確認する。位置が固定という要件は確定済みだが、座標自体は未指定。 |
| D03 | 開始姿勢は元の基本姿勢、各目標は独立・等確率の1〜6。 | P2前。サイコロの面配置は変えず、開始姿勢と生成方法を固定する。 |
| D04 | 0.01秒未満は切り捨て、同じ0.01秒は同記録。 | P2前。0.01秒単位は指定済みで、丸め方のみが案。 |
| D05 | 目標出現後に中断したプレイは参考記録とし、通常ベストとランキングへ入れない。 | P3と公開前。途中再開の可否と文言も一緒に決める。 |
| D06 | 元のタッチ向け・標準の速度は変えず、記録に操作設定IDを付ける。 | P1では継承を優先。ランキングを分けるなどの正式な比較条件はP4前に決める。 |
| D07 | 通常の再挑戦では固定座標を維持し、新しい目を生成する。 | P3前。同じ問題を選んで再挑戦する別機能は初回に追加しない。 |
| D08 | 低い秒数ほど上位のオンライン記録を別ゲームIDで扱う。 | P4前に既存接続契約を調査する。実装・公開は別許可。 |

D02〜D04が未確定の間でも、P1の流用確認は進められる。D05〜D08の未確定を理由に盤面・操作の流用まで停止する必要はないが、正式な記録受付は開始しない。

## 3. 採用しない内容の案内

[実装計画書](IMPLEMENTATION_PLAN.md)第2・3・7節を参照する。目標位置のランダム化、キャラクター変更、操作速度の無断統一、日替わり制、計測開始条件の変更、原作の特殊パネル追加は、指示整理によって採用されない。

## 4. 作業の許可範囲と方法の自由

共通の許可範囲と禁止事項は [AGENTS.md](../AGENTS.md) を正本とする。旧版の「今回は文書だけ」はP0の範囲であり、その後の通常実装を永久に禁止する指示ではない。今回の依頼はAI指示の整理であり、ゲーム本体は変更しない。

計画第5節の内部状態名、第8.1節の構造例、第10節のファイル名や分割は、同じ仕様・完成条件を満たすための方法の案である。通常実装では代案を選べるが、この節を使って上のD01〜D08のゲーム・記録条件や必須検査を変更してはならない。
