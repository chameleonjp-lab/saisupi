# サイスピ 受入検査 v1.1

本書は今後の検査計画である。実装の自動検査やiPhone実機検査を実施済みとする一覧ではない。計画時に実行した参照モデルの範囲は[計測と検証の資料](references/TIMING_AND_VALIDATION.md)へ分けて記録する。

## 1. 流用する見た目と操作

| ID | 操作・確認条件 | 合格条件 |
|---|---|---|
| V01 | 元版と新作を同じ画面サイズ・向きで表示する。 | 7×7の床、カメラ、盤面の向き、表示範囲が一致する。目標と新ルールの表示だけが差分である。 |
| V02 | サイコロの全方向の転がりを比較する。 | 形、目、面の対応、材質、移動の軌跡を変えていない。 |
| V03 | キャラクターを待機・登り・上昇・転がりで比較する。 | 元の形、寸法、色、姿勢の動きを維持し、削除・縮小・半透明化していない。 |
| V04 | 斜め4方向へフリックする。 | 元と同じ方向へ動き、距離と角度の判定値が同じである。 |
| V05 | 方向ボタン、矢印キー、WASDを操作する。 | 元の方向対応を維持し、二重入力にならない。 |
| V06 | 移動中に次の方向を1つ入力し、さらに別の方向を入れる。 | 計測中は元の1方向保持と同じ動作で、無制限の入力列をためない。 |
| V07 | タッチ向けと標準設定を読み込む。 | 移動時間を無断変更せず、プレイ途中で切り替わらず、記録に設定IDが残る。 |
| V08 | 縦横画面、文字拡大、画面端、指が離れる位置を試す。 | 追加表示が盤面・操作を遮らず、元からの回帰不具合がない。 |
| V09 | ホーム、ゲーム、結果の各画面を表示する。 | 効果音ボタンはゲーム画面だけに表示され、他の画面には残らない。 |
| V10 | タッチ向けとPC向けのサイコロ転がり時間を測る。 | タッチは180ms、PC/標準はサイノメ準拠の280msである。 |

## 2. 登る・目標出現・上昇・開始

| ID | 操作・確認条件 | 合格条件 |
|---|---|---|
| S01 | ゲーム画面で登らず待つ。 | 目標が出ず、時間が進まない。 |
| S02 | 床だけを移動する。 | 目標生成・計測開始をしない。 |
| S03 | 登り始めと登り途中を観測する。 | 目標と時計が先行しない。 |
| S04 | 埋まったサイコロへの登りを正常に完了する。 | 10か所が同時に現れ、上昇を始める。計測はまだ始まらない。 |
| S05 | 別プレイの登り完了通知を遅れて送る。 | 新しいプレイの状態・乱数・目標へ影響しない。 |
| S06 | 上昇の開始直後と完了直前を観測する。 | 表示は0.00秒で、一致判定と転がしを受け付けない。 |
| S07 | 上昇進行度を1へ進める。 | 最終位置・通常状態・開始時刻が同じ確定処理で設定される。 |
| S08 | 完全露出後に操作せず待つ。 | 最初の入力を待たず時間が進む。 |
| S09 | 同じ上昇完了通知を2回以上送る。 | 開始時刻を更新せず、目標を再生成しない。 |
| S10 | 登り中・上昇中に連打してから開始する。 | 状態境界の入力が無料の一手として残らない。 |
| S11 | 上昇中に描画の間隔を大きくする。 | 不完全露出で早く開始せず、完了を飛ばしたまま操作可能にならない。 |
| S12 | 目標生成・描画準備を故意に失敗させる。 | 不完全な10目標で開始せず、再試行可能な待機へ安全に戻る。 |

## 3. 固定10か所と上面一致

| ID | 操作・確認条件 | 合格条件 |
|---|---|---|
| T01 | 異なる乱数初期値で繰り返し開始する。 | 位置は同じ10か所で、目は1〜6の整数だけである。 |
| T02 | 同じ初期値・生成方式・配置版で再生成する。 | 10個の目とIDの対応が一致する。 |
| T03 | 範囲外、重複、開始サイコロと同じ座標を設定する。 | 開始前に不正な設定として拒否する。 |
| T04 | 複数目標が同じ目になった問題を遊ぶ。 | 正常な問題として扱い、勝手に引き直さない。 |
| T05 | 描画・保存・復帰・既達成目標への再訪を繰り返す。 | 問題の目は変わらず、余分に乱数を消費しない。 |
| T06 | 1〜6の各目で上面を一致させる。 | 各目とも同じ条件で自動達成する。 |
| T07 | 下面だけ一致、側面だけ一致の状態で着地する。 | 達成しない。 |
| T08 | 移動途中だけ目標に重なった見た目を作る。 | 座標と6面が確定するまで達成しない。 |
| T09 | キャラクターが床の目標を踏む。 | サイコロ上面の一致ではないので達成しない。 |
| T10 | 不一致で目標を通過する。 | 通行でき、追加罰を与えない。 |
| T11 | 達成済み目標へ再度一致させる。 | 達成数は増えず、音や保存を二重実行しない。 |
| T12 | 別の順番で10個を取る。 | 順番を強制せず、10IDすべてで完走する。 |
| T13 | 同じ目の隣接、1、既存の消去条件を作る。 | 旧消去・沈下・補充・300秒終了が作動しない。 |
| T14 | 1個達成した直後に次へ移動する。 | サイコロやキャラクターを消さず、演出で操作を止めない。 |
| T15 | 全方向に4回転、逆方向の往復を行う。 | 元の6面規則と一致し、見た目と内部値がずれない。 |

## 4. 時計・結果の一度だけの確定

| ID | 操作・確認条件 | 合格条件 |
|---|---|---|
| C01 | 偽の時計で開始・終了を指定する。 | 経過ミリ秒は終了−開始であり、フレーム数や表示更新回数に依存しない。 |
| C02 | 0、9、10、19、12349、12350、99999、100000ミリ秒を変換する。 | 切捨て案では0、0、1、1、1234、1235、9999、10000の0.01秒単位整数になる。 |
| C03 | 小数部分が0または1桁になる記録を表示する。 | 常に小数部2桁を表示する。100秒以上も切れない。 |
| C04 | 表示更新を止めた後、10個目を確定する。 | 表示の古い値ではなく時計の差分から記録する。 |
| C05 | 9個目で長時間待つ。 | 完走にせず、計測し続ける。 |
| C06 | 10個目の入力開始・移動途中・移動完了を別時刻で送る。 | 移動完了後の一致確定時だけに終了する。 |
| C07 | 10個目の完了通知を重複送信する。 | 結果と保存依頼が一度だけ確定する。 |
| C08 | 10個目の直前に次の方向を保持する。 | 完走後には動かない。 |
| C09 | 終了演出と通信を意図的に遅らせる。 | 完走スコアは増えない。 |
| C10 | OS時計を前後へ変更する。 | 同一ページ内の競技時間が逆行しない。 |
| C11 | 同じ0.01秒で未丸め時間だけ異なる記録を比較する。 | 隠れた時間差で順位や自己ベスト更新を変えない。 |
| C12 | 未開始、未完走、0、負数、NaN、Infinity、不正形式を保存へ渡す。 | 正式な完走記録として受理しない。 |
| C13 | 描画30/60/120回毎秒で同じ時刻付き確定イベント列を渡す。 | 純粋な計測結果は一致する。実機の遅延検査とは分けて記録する。 |
| C14 | 10個目の目標を一致させる。 | 成功SE・光柱・待ち時間を追加せず、移動完了後にスコア結果画面を表示する。1〜9個目の成功演出は維持する。 |

## 5. 中断・再戦・記録・オンライン

| ID | 操作・確認条件 | 合格条件 |
|---|---|---|
| R01 | 登る前・途中・上昇中・計測中・完走後に画面を離れる。 | 各状態の中断方針どおりで、無料の考慮時間を有効記録へ戻さない。 |
| R02 | 画面のロック、復帰、再読み込みを行う。 | 前の絶対時計を新しいページの時計と引き算しない。 |
| R03 | 描画機能の消失と復元を試す。 | 古い上昇完了・移動完了が再発火して正式記録を作らない。 |
| R04 | 方向だけ同じまま回転通知・サイズ変更を送る。 | 止まったままにならず、不要な記録無効化をしない。 |
| R05 | 計測中の移動半ばで中断する。 | 復帰時の座標と6面が一致し、参考記録の区分が消えない。 |
| R06 | 再挑戦を20回行い、前プレイの通知を混ぜる。 | 10座標は固定、目標・時間・入力・達成状態は新しくなり、資源や購読が増え続けない。 |
| R07 | 保存不能・破損記録・未知版を用意する。 | 遊びを壊さず、他の記録を削除しない。 |
| R08 | 古い別タブから遅い記録を保存する。 | 最新の短い自己ベストを上書きしない。 |
| R09 | 同じ公開ドメインのサイノメの保存値を用意する。 | 読み替え、変更、削除、誤送信をしない。 |
| R10 | 異なる操作速度・ルール版・配置版の記録を用意する。 | 承認した区分に従い、比較不可の記録を無断で混ぜない。 |
| R11 | 送信を重複させ、順序を逆転し、途中で通信を切る。 | 同じプレイの記録を重複登録せず、確定したスコアを変えない。 |
| R12 | 12.34秒、12.35秒、12.34秒をランキングへ渡す。 | 短い順で同点の扱いが一致し、ポイントに変換されない。 |
| R13 | ホーム、結果、共有、名前未入力を確認する。 | 丁寧な日本語で操作でき、300秒・連鎖など旧ルールの説明が残らない。 |

## 6. 検査の分担と証拠

P1ではV系、P2ではS・T・C系、P3ではR01〜R10とR13、P4ではR10〜R12、P5では実機を含めた再検査を行う。状態ごとの検査はテスト用時計と固定乱数を使って再現できるようにする。

iPhone 17 Pro Safariを主対象に、縦・横・ブラウザのバー表示差・文字拡大・アプリ切替・画面ロックを確認する。パソコンでは継承した矢印キーとWASDの回帰を確認する。自動ブラウザの成功をiPhone実機合格と呼ばない。

証拠には対象コミット、ブラウザと端末、画面寸法、操作設定、入力手順、開始・終了のイベント時刻、目標IDと目、期待値と実測値を残す。個人名やキーを含むログはそのまま公開しない。

配置案Aについて全目が到達可能という参照モデルの結果はあるが、固定10目標の最短巡回手数・人間の適正クリア時間・全端末の実時間精度は未測定である。
