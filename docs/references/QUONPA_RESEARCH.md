# PS1『クオンパ』調査資料

確認日: 2026-09-14

目的: サイスピの設計で参考にする仕組みと、今回採用しない要素を区別する。

[実装計画書](../IMPLEMENTATION_PLAN.md)へ戻る。

## 1. 確認できた中心ルール

PS1版のゲーム内説明画像には、キューブの上の色を合わせるとクリアパネルを消せるという説明がある。したがって、参考にする中心ルールは床に接する下面ではなく、見える上面と対象の一致である。

出典: [PS1版の説明画面画像](https://psxdatacenter.com/images/screens/J/C/SLPS-01026/ss4.jpg)。ゲーム画面そのものを確認した。画像の保存先は第三者サイトであり、本調査でゲーム機を操作したものではない。

PSX Data Centerは、T&E SOFT、1997年10月9日、製品番号SLPS-01026としてPS1版を掲載している。ステージクリア、1人・2人サバイバル、移動数制限のパズル、練習を記載し、ステージ数を100としている。この部分はサイトの整理情報であり、全モード・全100面をプレイ確認した結果ではない。

出典: [PS1版の作品資料](https://psxdatacenter.com/games/J/C/SLPS-01026.html)。

## 2. 仕組みから読み取れるゲーム性

ここからは調査したルールに基づく設計上の分析であり、原作の開発者が述べた意図ではない。

移動するたびに上面が変わるため、目的地への距離だけでなく、どの向きで到着するかを考える必要がある。近い経路がそのまま少ない手数の経路になるとは限らない。

複数の目標を好きな順に達成できるルールなら、次に取る目標と、その後の向きも判断材料になる。時間を競う場合は、経路を考える時間と正確に操作する時間の両方が結果へ表れる。

サイスピではこの面合わせの考え方を用いる。原作の色、画面、音、名称、キャラクターを流用する計画ではない。サイノメの既存資産とユーザーの新ルールを優先する。

## 3. サイスピへの対応

| 参考にする考え方 | 今回の実装計画 |
|---|---|
| 目的の場所へ、正しい上面で到着する。 | サイコロの上面と固定10か所の目を一致させる。 |
| 移動と面の向きを一緒に考える。 | 元の6面規則を継承し、到着後に一致判定を行う。 |
| 連続した判断と操作を楽しむ。 | 1〜9個目の達成演出で操作を止めず、10個目で終了する。 |

色合わせを数の目合わせへ置き換えること、固定10か所、登ると目標が現れること、完全露出で時計を始めること、0.01秒の完走記録はサイスピ側の指定・設計である。原作と同じ仕様だったと説明しない。

## 4. 採用しない内容と不明な点

特殊パネル、対戦、100面構成、移動数制限、原作のスコア計算を初回実装へ追加しない。原作に存在するという理由だけで今回の要件にしない。

PS1版の細かな得点式、特殊パネルの全条件、全モードの制限時間、実機での入力遅延は、この調査では確定していない。スーパーファミコン版やその復刻版の説明を、PS1版の確定仕様として混ぜない。

前の会話にあるランダム盤面100件の最短手数の数値は、クオンパの公式データではない。再現用の盤面一覧と実行物を今回確認しておらず、本作の位置も固定へ変更されたため、計画の根拠に用いない。本作の配置案は別の参照モデルで到達可能性だけを検証した。

## 5. 資料の保存方針

このリポジトリには、確認した出典、要約、今回の設計上の解釈を保存する。原作画像、マニュアル全文、音源、ゲームデータのコピーは保存していない。外部資料の内容と、ユーザー指定・設計案を明確に区別する。
