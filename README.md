# saisupi

サイスピ。サイノメの盤面・サイコロ・操作・キャラクターを使い、サイコロの上面をそろえる速さを競うブラウザゲームです。

## 現在の実装

現行計画書のP1〜P2として、次の土台を実装しています。

- 7×7盤面、元版と同じカメラ、サイコロ、キャラクター
- 元版と同じ斜めフリック、方向ボタン、矢印キー、W・A・S・D
- 埋まったサイコロへ登る動きと、サイコロが上がりきる動き
- 固定10か所への光る目標表示、上昇完了から始まる経過時間表示
- 移動完了後のサイコロ上面一致、達成数、0.01秒単位の暫定スコア表示

配置案A・独立等確率の目生成・0.01秒未満切捨ては、未確定事項を明示したP2の暫定実装です。結果画面、自己ベスト、保存、ランキング、中断記録はまだ実装していません。検査結果と未確認事項は [P2実装記録](docs/P2_IMPLEMENTATION.md) と [P1実装記録](docs/P1_IMPLEMENTATION.md) にまとめています。
