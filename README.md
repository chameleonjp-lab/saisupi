# saisupi

サイスピ。サイノメの盤面・サイコロ・操作・キャラクターをそのまま使い、固定された10か所の目とサイコロの上面をそろえるまでの秒数を競うブラウザゲームです。

**現在は計画書のみです。ゲーム本体はまだ実装していません。**

キャラクターが埋まったサイコロに登ると、決められた10か所にランダムな目が光って現れます。サイコロが完全に露出した瞬間に計測を始め、10個すべてをそろえた瞬間に止めます。スコアは0.01秒単位の経過秒数で、短いほどよい記録です。

## 開発上の境界

実装先はこのリポジトリだけです。流用元 `chameleonjp-lab/sainome` は変更しません。サイノメの外観や操作を再設計せず、新しい開始条件・目標判定・時計・結果処理を分離して実装します。

作業はブランチとDraft PRで管理します。`main`への直接push、マージ、自動マージ、保護の緩和、本番データベースの変更、公開設定の変更は行いません。今回の依頼は文書の作成と保存までです。
