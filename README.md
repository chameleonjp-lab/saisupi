# saisupi

サイスピ。サイノメの盤面・サイコロ・操作・キャラクターを使い、サイコロの上面をそろえる速さを競うブラウザゲームです。

## 現在の実装

現行計画書のP1〜P4と最新追加修正として、次の土台を実装しています。

- 7×7盤面、元版と同じカメラ、サイコロ、キャラクター
- 元版と同じ斜めフリック、方向ボタン、矢印キー、W・A・S・D
- 埋まったサイコロへ登る動きと、サイコロが上がりきる動き
- 固定10か所への光る目標表示、上昇完了から始まる経過時間表示
- 移動完了後のサイコロ上面一致、達成数、0.01秒単位の暫定スコア表示
- 1〜9個目の一致マスから3秒立ち上がる半透明の光柱と、サイノメと同じ成功SE。10個目は演出待ちなしで結果画面へ遷移
- 目標、盤面、サイコロ、キャラクターの材質・輪郭・発光・目や表情の描画品質向上
- 効果音ボタンはゲーム画面だけに表示。タッチのサイコロ転がりは180ms、PC/標準はサイノメ準拠の280ms
- 各目標の達成タイムを表示する結果画面、再プレイ、ホーム導線
- URLを本文へ直接書く共有文、3ステップの説明、カメレオンJPの実験場リンク
- 既存Supabase RPCを使うプレイ開始記録・スコア登録・上位10件取得、自己ベストとランキング表示

配置案A・独立等確率の目生成・0.01秒未満切捨ては、未確定事項を明示した暫定実装です。長押しコピー抑止、効果音デフォルトオン、OGPサムネイル、リタイアと再プレイもP4で追加しました。Supabase側にはサイスピ用の`saisupi`を登録済みで、公開用キーによる登録確認・プレイ開始記録・スコア登録・上位10件取得の実通信を確認しています。今回の追加修正と未確認事項は [P4実装記録](docs/P4_IMPLEMENTATION.md)、[進行記録](docs/PROGRESS.md)、[Supabaseランキング連携確認](docs/SUPABASE_RANKING_SETUP.md)、[P3実装記録](docs/P3_IMPLEMENTATION.md)、[P2実装記録](docs/P2_IMPLEMENTATION.md)、[P1実装記録](docs/P1_IMPLEMENTATION.md) にまとめています。
